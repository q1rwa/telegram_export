# Политика конфиденциальности — «Экспорт переписок — TXT»

**Редакция от 1 ноября 2026 года**

Приложение «Экспорт переписок — TXT» (далее — Приложение) — независимый инструмент для сохранения текста выбранного личного чата Telegram в TXT-файл на устройстве пользователя. Приложение не является официальным продуктом Telegram и не связано с Telegram FZ-LLC.

**Контакт разработчика по вопросам конфиденциальности:** [@s314rgy](https://t.me/s314rgy).

## 1. Какие данные используются и зачем

Для входа в собственный аккаунт Telegram Приложение использует номер телефона, код авторизации, при необходимости облачный пароль и временные QR-токены. Для работы также используются авторизованная сессия Telegram, список доступных личных диалогов и текст сообщений выбранного диалога.

Дополнительно пользователь может указать настройки SOCKS5-прокси (адрес, порт, логин, пароль). Эти сведения нужны только для подключения к Telegram по желанию пользователя.

Цели обработки: авторизация пользователя, отображение списка его личных диалогов, экспорт текста выбранной переписки и сохранение файла в указанное пользователем место.

## 2. Передача данных

Приложение подключается к серверам Telegram для авторизации и чтения данных аккаунта через Telegram API. Обработка этих соединений также регулируется [политикой конфиденциальности Telegram](https://telegram.org/privacy).

Приложение **не отправляет экспортированные переписки, коды входа или сессии на сервер разработчика** и не содержит отдельных средств рекламной аналитики.

Созданный TXT-файл сохраняется в место, выбранное пользователем через системный интерфейс Android. Если пользователь выбрал облачное хранилище или сторонний файловый сервис, сохранённый TXT-файл может обрабатываться соответствующим сервисом по его правилам.

Кнопка «тгк» открывает канал разработчика в Telegram только по инициативе пользователя.

## 3. Хранение и защита

Данные авторизованной сессии и сохранённые настройки размещаются в защищённом внутреннем хранилище Приложения на устройстве, в зашифрованном виде. Ключ шифрования хранится в Android Keystore.

Во время экспорта создаётся временный TXT-файл в кэше Приложения. По завершении сохранения или отмене операции временный файл удаляется; при следующем запуске также выполняется очистка оставшихся временных файлов.

Временные QR-токены для входа не сохраняются в постоянном хранилище.

TXT-файл, сохранённый пользователем, **не шифруется Приложением**. Пользователь самостоятельно управляет местом его хранения, доступом к файлу и удалением.

## 4. Сроки хранения и удаление

Данные сессии и настройки хранятся на устройстве, пока пользователь не выйдет из аккаунта в Приложении либо не удалит данные Приложения/само Приложение.

Выход из аккаунта завершает сессию Telegram и удаляет хранящиеся в Приложении данные входа и настройки. Сохранённые пользователем TXT-файлы при этом **не удаляются**; их можно удалить вручную через файловый менеджер.

## 5. Пользователь и третьи лица

Экспорт переписки может включать персональные данные других участников диалога. Пользователь несёт ответственность за законность дальнейшего использования и распространения сохранённого текста. Приложение не предназначено для получения доступа к чужим аккаунтам или перепискам без авторизации.

Политика может изменяться при обновлении функций Приложения. Актуальная версия размещается в этом документе.
